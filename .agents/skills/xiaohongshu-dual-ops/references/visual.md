# B 视觉设计制作规范

每件作品先填写：用途、目标读者、要完成的动作、必须出现的内容、输出尺寸/格式、品牌与字体素材、交付授权。

- 简历：用虚构且明确标注的示例人物，写完整经历条目；展示信息层级和招聘阅读路径，不伪造真实履历。
- PPT：至少展示封面、目录/结构、信息页与总结页；给真实可替换的内容区域和编辑说明。不要只交一张封面。
- 海报与广告：写清产品卖点、受众、场景、主次文案和行动信息；虚构品牌标注为概念案例，不捏造销量或功效。
- 电商详情页：包含信息架构、规格、卖点证据、使用场景、FAQ 和必要声明；真实商品数据只能来自用户提供且可核对的资料。

统一核对移动端阅读、文字准确、对齐、对比度、裁切、字体授权和可编辑性。原创视觉表达须有新的构图与概念，不仿制特定品牌的标志性视觉或搬运他人模板。模板销售版需提供源文件、预览图、兼容版本、授权条款和售后说明。
